# Study Timer App
A focused productivity tool designed to help students manage study sessions effectively — especially tailored for UNSW students balancing coursework, assignments, and exam preparation.

This is the github repository we'll be using to collaborate and share edits on all aspects of this project, remember to procide detailed committal comments with updates about all changes made.

Please join the figma!! We've made some awesome progress so far, just shoot me a message and I'll add you :D

# Purpose
The Study Timer App is built to:

Encourage structured study sessions

Promote deep focus using timed intervals

Help students track and manage study time

Reduce procrastination and burnout

While suitable for anyone, it is particularly designed with UNSW students in mind — supporting semester-based study cycles, assignment deadlines, and exam blocks.
